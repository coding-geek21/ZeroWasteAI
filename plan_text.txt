# Food Waste Intelligence Platform – Complete Project Plan
## Project Name: **ZeroWaste AI**
## Tagline
*"See your food. Save your food. Feed your community."*
---
## 1. Problem Statement
**Theme:** Sustainability & Social Impact
**The Problem:**
- 1/3 of all food produced globally (~1.3 billion tons/year) is wasted
- Restaurants lose 4-10% of purchased food before it reaches customers
- Grocery stores discard $15.6 billion in unsold fruits and vegetables annually
- Food waste generates 8-10% of global greenhouse gas emissions
- Meanwhile, 828 million people go hungry every day
**Why existing solutions fail:**
- Manual inventory tracking is error-prone and time-consuming
- Expiry management is reactive (discard after expired) instead of predictive
- No unified system connects inventory visibility → demand prediction → waste prevention actions
- Small businesses can't afford enterprise waste management platforms
**Our Solution:**
An AI-powered platform that uses computer vision to understand food inventory, predicts what will expire and when, and orchestrates waste prevention actions – dynamic discounts, recipe suggestions, and donation matching with local food banks.

## 5. AI Agent Detailed Design
### 5.1 Vision Agent – Food Recognition & Assessment
**Purpose:** Analyze food images to identify items, estimate quantities, assess freshness, and predict expiry dates.
**Model:** Gemini 2.5 Pro (multimodal)
**System Prompt:**
```
You are a food inventory analysis AI. When given an image of food items
(in a fridge, on a shelf, in storage, or on a counter), you must:
1. IDENTIFY every distinct food item visible in the image
2. ESTIMATE the quantity of each item (count, weight, or volume)
3. ASSESS the freshness on a 0-100 scale based on visual cues:
   - Color (browning, yellowing, discoloration)
   - Texture (wilting, wrinkling, softness indicators)
   - Mold or spoilage signs
4. ESTIMATE days until expiry based on:
   - The food type's typical shelf life
   - Current freshness assessment
   - Storage conditions visible in the image (fridge vs counter)
5. READ any visible labels, dates, or packaging information
Respond ONLY in this JSON format:
{
  "items": [
    {
      "name": "string (specific name, e.g., 'Roma Tomatoes' not just 'vegetable')",
      "category": "produce|dairy|meat|bakery|frozen|canned|beverage|other",
      "quantity": number,
      "unit": "kg|lbs|units|liters",
      "freshness_score": number (0-100, where 100 is perfectly fresh),
      "estimated_days_left": number,
      "storage_condition": "refrigerated|room_temperature|frozen",
      "visible_issues": "string or null (describe any spoilage signs)",
      "confidence": number (0-1, your confidence in this identification)
    }
  ],
  "image_quality": "good|acceptable|poor",
  "storage_assessment": "string (brief note on storage conditions observed)",
  "total_items_detected": number
}
```
**Example Input/Output:**
Input: Photo of a restaurant fridge shelf
Output:

### 5.2 Prediction Agent – Waste Forecasting
**Purpose:** Analyze inventory data + historical patterns to predict waste risk and demand.
**Model:** Gemini 2.5 Flash (fast inference)
**System Prompt:**
```
You are a food waste prediction AI for businesses. Given current inventory
data and optional historical sales patterns, you must:
1. CALCULATE waste risk for each item (HIGH/MEDIUM/LOW):
   - HIGH: Will likely waste within 24 hours without intervention
   - MEDIUM: Will likely waste within 48-72 hours without intervention
   - LOW: Safe for 3+ days
2. PREDICT demand for each item category based on:
   - Day of week patterns (weekends vs weekdays)
   - Seasonal trends
   - Historical sales if provided
3. IDENTIFY items that should be prioritized for action
4. CALCULATE estimated financial loss if no action is taken
Respond in JSON:
{
  "predictions": [
    {
      "item_id": "string",
      "item_name": "string",
      "risk_level": "HIGH|MEDIUM|LOW",
      "waste_probability": number (0-1),
      "hours_until_critical": number,
      "estimated_demand_next_24h": number,
      "surplus_quantity": number (quantity - predicted demand),
      "financial_risk": number (cost if wasted in USD),
      "priority_rank": number (1 = most urgent),
      "reasoning": "string (brief explanation)"
    }
  ],
  "summary": {
    "total_items_at_risk": number,
    "total_financial_risk": number,
    "top_action_needed": "string"
  }
}
```
### 5.3 Action Agent – Smart Recommendations
**Purpose:** Generate specific, actionable waste prevention recommendations.
**Model:** Gemini 2.5 Pro (reasoning + creativity)
**System Prompt:**
```
You are a food waste prevention strategist AI. Given inventory items at risk
of waste with their predictions, generate SPECIFIC, ACTIONABLE recommendations.
For each at-risk item, suggest ONE OR MORE of these action types:
1. DISCOUNT: Dynamic pricing to increase sales
   - Calculate optimal discount % that maximizes revenue recovery
   - Consider item category and margin
2. RECIPE: Creative recipes using at-risk ingredients
   - Combine multiple at-risk items into one recipe when possible
   - Include prep time, serving count, and difficulty
   - Prefer recipes that use the MOST at-risk ingredients together
3. DONATE: Match with nearby food banks
   - Only suggest for items with 24+ hours of safe life remaining
   - Include quantity suitable for donation
4. ALERT: Notify staff for immediate use
   - For items in critical state needing same-day use
5. COMPOST: Last resort for items past safe consumption
   - Track for waste metrics even if not preventable
Respond in JSON:
{
  "actions": [
    {
      "type": "DISCOUNT|RECIPE|DONATE|ALERT|COMPOST",
      "priority": "URGENT|HIGH|MEDIUM",
      "target_items": ["item_id1", "item_id2"],
      "title": "string (short action title)",
      "description": "string (detailed action description)",
      "details": {
        // For DISCOUNT:
        "suggested_discount_percent": number,
        "original_price": number,
        "new_price": number,
        "expected_sell_through": number (0-1),
        // For RECIPE:
        "recipe_name": "string",
        "ingredients_used": [{"name": "string", "quantity": "string"}],
        "additional_ingredients_needed": [{"name": "string", "quantity": "string"}],
        "prep_time_minutes": number,
        "servings": number,
        "instructions": ["step 1", "step 2", ...],
        "difficulty": "easy|medium|hard",
        // For DONATE:
        "suitable_quantity": "string",
        "food_bank_match": "string (name of nearby food bank)",
        "pickup_deadline": "string",
        // For ALERT:
        "alert_message": "string",
        "deadline": "string"
      },
      "estimated_savings": {
        "money_usd": number,
        "food_kg": number,
        "co2_kg": number,
        "meals_equivalent": number
      }
    }
  ],
  "total_potential_savings": {
    "money_usd": number,
    "food_kg": number,
    "co2_kg": number
  }
}
```

## 6. API Endpoints – Detailed Specification
### 6.1 Authentication
```
POST   /api/auth/register    → Register new user/business
POST   /api/auth/login       → Login (Firebase Auth token)
GET    /api/auth/profile     → Get user profile
PUT    /api/auth/profile     → Update profile & preferences
```
### 6.2 Inventory Management
```
POST   /api/scan                     → Upload image → Vision Agent → returns identified items
  Request:  { image: base64_string }
  Response: { items: [...], scan_id: string }
POST   /api/inventory                → Add item(s) manually or confirm scan results
  Request:  { items: [{ name, category, quantity, unit, expiry_date, cost_per_unit }] }
  Response: { added: [...item_ids] }
GET    /api/inventory                → List all active inventory
  Query:    ?risk=HIGH&category=produce&sort=expiry
  Response: { items: [...], total: number }
PUT    /api/inventory/{id}           → Update item (quantity change, status change)
  Request:  { quantity: number, status: "consumed"|"wasted"|"donated" }
DELETE /api/inventory/{id}           → Remove item
POST   /api/pos/import               → Import POS/sales data CSV
  Request:  multipart/form-data with CSV file
  Response: { imported: number, matched_to_inventory: number }
```
### 6.3 AI Predictions & Actions
```
GET    /api/predictions              → Get waste predictions for all inventory
  Response: { predictions: [...], summary: {...} }
GET    /api/actions                  → Get AI-recommended actions
  Query:    ?type=RECIPE&priority=URGENT
  Response: { actions: [...], total_savings: {...} }
POST   /api/actions/{id}/accept      → Accept a suggested action
POST   /api/actions/{id}/complete    → Mark action as completed
POST   /api/actions/{id}/dismiss     → Dismiss a suggestion
POST   /api/actions/ask              → Chat with AI about inventory
  Request:  { question: "What can I make with the expiring items?" }
  Response: { answer: string, suggested_actions: [...] }
```
### 6.4 Dashboard & Impact
```
GET    /api/dashboard                → Dashboard summary metrics
  Response: {
    inventory_count: number,
    items_at_risk: number,
    actions_pending: number,
    today_savings: { money, food_kg, co2_kg },
    weekly_trend: [{ date, waste_kg, saved_kg }]
  }
GET    /api/impact                   → Cumulative impact metrics
  Query:    ?period=week|month|year
  Response: {
    total_food_saved_kg: number,
    total_money_saved_usd: number,
    total_co2_prevented_kg: number,
    total_meals_donated: number,
    trend: [{ date, value }],
    badges: [{ name, description, earned: boolean }]
  }
GET    /api/impact/report            → Generate PDF impact report
  Response: PDF file stream
```
### 6.5 Food Banks
```
GET    /api/food-banks               → List nearby food banks
  Query:    ?lat=xx&lng=yy&radius_km=10
  Response: { food_banks: [...] }
POST   /api/donations                → Create a donation record
  Request:  { food_bank_id, items: [{item_id, quantity}], pickup_time }
  Response: { donation_id, status: "scheduled" }
```

**Key Code – vision_agent.py:**
```python
import google.genai as genai
from google.genai import types
import json
import base64
class VisionAgent:
    def __init__(self, api_key: str):
        self.client = genai.Client(api_key=api_key)
        self.model = "gemini-2.5-pro-preview-06-05"
    async def analyze_image(self, image_base64: str) -> dict:
        image_part = types.Part.from_bytes(
            data=base64.b64decode(image_base64),
            mime_type="image/jpeg"
        )
        response = await self.client.aio.models.generate_content(
            model=self.model,
            contents=[
                types.Content(
                    role="user",
                    parts=[
                        image_part,
                        types.Part.from_text(VISION_SYSTEM_PROMPT)
                    ]
                )
            ],
            config=types.GenerateContentConfig(
                response_mime_type="application/json",
                temperature=0.2,
            )
        )
        return json.loads(response.text)
```
